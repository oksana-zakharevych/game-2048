# 2048 Game

An interactive browser implementation of the classic 2048 puzzle game where players slide and merge numbered tiles on a 4×4 grid to reach the 2048 tile and track their score.

## Live Preview

- [Live Demo](https://oksana-zakharevych.github.io/game-2048/)

## Technologies Used

- HTML5
- SCSS / CSS3
- JavaScript (ES6+ Modules)

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/oksana-zakharevych/game-2048.git
cd game-2048
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Run the project locally:

```bash
npm start
# or
yarn start
```
